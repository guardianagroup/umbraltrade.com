# umbraltrade.com

Web de Umbral Trade: radar de mercados en tiempo real que avisa cuando un activo llega a un soporte o una resistencia, con sus tres zonas de entrada.

Página estática servida con GitHub Pages en https://umbraltrade.com.

- `index.html` es toda la web en un solo archivo. Se genera a partir del código fuente; no se edita a mano.
- `CNAME` indica el dominio.
- `404.html` devuelve a la portada.

Umbral Trade es una herramienta de análisis. No es asesoramiento financiero ni garantiza resultados.
